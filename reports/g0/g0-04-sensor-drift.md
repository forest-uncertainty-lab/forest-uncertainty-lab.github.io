# G0-04: Suomi NPP against NOAA-20, 2018–2025

Generated by `scripts/g0_checks.py` on 2026-10-22. Source: FIRMS VIIRS yearly files
for Indonesia, Suomi NPP (`https://firms.modaps.eosdis.nasa.gov/data/country/viirs-snpp/{year}/viirs-snpp_{year}_Indonesia.csv`) and NOAA-20 (`https://firms.modaps.eosdis.nasa.gov/data/country/viirs-jpss1/{year}/viirs-jpss1_{year}_Indonesia.csv`).

Both satellites carry a VIIRS instrument. If one instrument's detection rate drifted over the years,
the ratio between their counts would drift with it. A steady ratio rules out drift in one of them
relative to the other, not a drift both share.

- Counts are rows anywhere in Indonesia, every confidence class and fire type, static sources included.
- Dates are UTC, as FIRMS cuts the files. Only dates on which both files have rows are used; a date
  one of them lacks is a likely data gap. Gaps of part of a day are not detected.
- Ratio: Suomi NPP rows per NOAA-20 row over the dates used. The 95% interval comes from resampling
  whole weeks (2,000 resamples, fixed seed), as fire episodes run over several days.
